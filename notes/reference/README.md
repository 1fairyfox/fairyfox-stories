fairyfox.io hub) and add project-specific references alongside them:

- `cross-project-sync.md` — how this project pulls hub standards
- `adoption-manifest.md` — the **per-standard record of what's actually adopted** (read by
  the release gate; `copied-only ≠ adopted`)
- `readme-cross-links.md` — the hub `readme.md` standard, mirrored under a distinct name to
  avoid the case-collision with this folder's `README.md`
- `deployment.md`, plus any project-specific lookups (error→fix tables, patterns)
